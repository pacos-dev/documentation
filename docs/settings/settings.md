# Configuration

Coupler is configured directly from the **Application → Settings** window.  
This module provides tabs that allow you to manage both the behavior of the system itself and the configuration of each installed plugin.

Below you will find descriptions of the available configuration tabs.

---

## **[API Access](./apiAccess)**
Configure access to Coupler’s API.  
This section allows you to define authentication methods, tokens, and endpoints to ensure secure integration with external tools and services.

---

## Default Permissions
Set default permissions for new users and guest accounts.  
If no specific configuration is applied, these defaults will determine the baseline access level for accounts created in the system.

---

## **[Plugin Management](./pluginManagement)**
Manage installed plugins.  
From this tab you can:
- Enable or disable plugins
- Install new plugins
- Uninstall existing plugins

This ensures that Coupler remains modular and adaptable to your team’s needs.

---

## **[System](./system)**
Control system-level operations.  
Options include:
- Updating Coupler to the latest version
- Restarting the system when required

---

## **[System Access](./systemAccess)**
Manage access to the system itself.  
Here you can configure guest account or enable/disable registration panel.

---

## Users & Permissions
Administer users and their roles.  
This tab allows you to:
- Create and manage user accounts
- Assign roles and permissions
- Control access to modules and resources

---

:::tip[Flexibility]
All settings can be adjusted at any time to adapt to your workflow.  
However, note that some installation mode choices (Personal vs Group) are fixed once selected during installation.
:::
