# Getting Started

Welcome to PacOS. Use this guide to find the quickest path for your goal.

## I want to run PacOS

Start with the [Installation guide](/docs/user/installation). It is the place to begin if you want to get an instance running before exploring the features.

After installation, continue to the [User guide](/docs/user) to learn how to work with PacOS.

## I want to learn what PacOS can do

Read the [User guide](/docs/user) for an overview of the product and its workflows. You can also visit the [PacOS homepage](https://pacos.dev/) for a high-level introduction.

## I want to develop or contribute

Go to the [Developer Guide](/docs/developers) for developer-focused documentation.

If your goal is to extend PacOS, start there and follow the plugin-development instructions provided by the project.

## Suggested path

1. Follow the [Installation guide](/docs/user/installation).
2. Explore the [User guide](/docs/user).
3. When you are ready to extend or contribute to PacOS, continue to the [Developer Guide](/docs/developers).

If you get stuck, check the relevant guide first so that installation steps, usage instructions, and development details stay easy to find.
