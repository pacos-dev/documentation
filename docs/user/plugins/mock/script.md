# Response Script Tab

The **Response Script tab** allows defining dynamic behavior for responses using JavaScript.  
Scripts are configured at the **[action](action.md) level**.  
When the checkbox **"Script enabled"** is selected, the script defined in the tab will be used to generate or manipulate the response.

![Mock script screenshot](/img/docs/plugins/mock-script.png)
---

## Context Variables

Scripts have access to two main context variables:

- **`request`**  
  Represents the incoming HTTP/SOAP request.  
  Provides access to request body, headers, URL, and method.

- **`response`**  
  Represents the outgoing response.  
  Allows manipulation of body, headers, HTTP status code, or switching to another predefined response.

---

## Examples of Usage

Here are some simple examples of how scripts can be used:

1. **Logging a simple message**  
```javascript
console.log("Request received");  
```

2. **Logging a variable value**  
```javascript
console.log(request.url);  
```

3. **Checking request header and logging**  
```javascript
if (request.headers["Content-Type"] === "application/json") {  
    console.log("JSON payload detected");  
}  
```

4. **Changing response body**  
```javascript
response.body = "Dynamic response generated by script";  
```

5. **Modifying HTTP status code**  
```javascript
response.httpCode = 201;  
```

6. **Switching to another configured response**  
```javascript
if (request.method === "POST") {  
    response.setResponseByName("postResponse");  
} else {  
    response.body = "Default response for non-POST";  
}  
```

## System Variables

Scripts can also use **system variables** defined at the collection or server level.  
This allows responses to be adapted dynamically depending on configuration values.

Example usage:
- Checking if the request URL contains a variable value.
- Returning a different response depending on the variable’s state.

---


## Debugging

During script execution, every log created with `console.log()` will be displayed in the **Script Logs tab**.  
This tab appears below the script editor and shows logs in real time while handling requests.

Logs are useful for:
- Inspecting incoming request data.
- Verifying variable values.
- Debugging response manipulation logic.
- Ensuring scripts behave as expected during testing.


## Structure

The Response Script tab provides:
1. **Script enabled checkbox** – activates script-based response handling.
2. **Script editor** – where JavaScript code is defined.
3. **Context variables** – `request` and `response` objects for full control.
4. **System variables support** – enables dynamic behavior based on configured variables.
5. **Script Logs tab** – displays logs generated during request handling.
